# Named MacKanban

The app is called MacKanban, with bundle ID `com.onethingwell.mackanban`, following MacJot (`com.onethingwell.macjot`). Apple's trademark guidelines don't allow "Mac" in a third-party product name, and the App Store can reject it. We accept that because, like MacJot, MacKanban is released on GitHub only. The name is settled before the first build, because changing it later means a new bundle ID, which loses the user's settings, login item and the Core Data store's location.
